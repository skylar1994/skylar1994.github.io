PART 1：N3 生活宇宙（上）

习惯养成 / 时间顺序 / 推测 / 目的愿望 / 条件 / 授受请求 / 传闻表达。

🌱【习惯养成宇宙】（N3）

核心问题：这是自己努力？自然变化？个人决定？规则/环境决定？

①～ようにする努力培养习惯 / 努力让自己做到
毎日、日本語を勉強するようにしている。
  • 🧠 自己控制 / 自己坚持 / 自己训练
  • 关键词：努力让自己做到
②～ようになる练着练着自然会了 / 结果变化 / 能力变化
日本語が話せるようになった。
  • 🧠 能力变化 / 习惯形成 / 自然成长
③～ことにする我决定 / 自己拍板
来年、日本へ行くことにした。
  • 🧠 自己拍板 / 自己决定
④～ことになる公司/学校/规则决定 / 环境决定
転勤することになった。
  • 🧠 别人决定 / 环境决定 / 制度决定

🕒【时间顺序宇宙】（N3）

①～てから做完A → 做B
ご飯を食べてから勉強する。
②～たところだ刚刚完成
今、帰ったところです。
③～ところだ正准备
今から出かけるところだ。
④～ているところだ正在进行
今、食べているところです。
⑤～たばかりだ虽然过去一阵子，但感觉：刚刚！（主观）
日本へ来たばかりです。
  • 🧠 主观上的：才……

🤔【推测宇宙】（N3）

①～ようだ像……（自己观察/自己判断）
雨が降るようだ。
  • 🧠 自己观察 / 自己判断
②～らしい听说……（别人说/新闻说/网络说）
明日は雨らしい。
③～みたいだ口语版：～ようだ
おいしいみたいだ。
  • 注意：表达“看起来好吃”更常用 おいしそう（样态）。
④～はずだ逻辑推理：应该……
医者だから、知っているはずだ。
  • 🧠 根据已知条件 → 推导结果

🎯【目的愿望宇宙】（N3）

①～ために为了梦想
日本へ行くために勉強する。
②～ように为了能够……（能力变化）
合格できるように頑張る。
  • 区别：主动目的＝ために / 能力变化＝ように
③～ようと思う准备开始做
毎日運動しようと思う。
④～つもりだ已经决定
留学するつもりです。

🔀【条件宇宙】（N3）

条件四兄弟：万能＝たら / 逻辑＝ば / 话题＝なら / 自然规律＝と

①～たら如果……（最万能）
②～ば只要……（逻辑条件）
③～なら既然说到……
日本へ行くなら、京都がおすすめ。
④～と自动发生（自然规律）
春になると暖かくなる。

❤️【授受请求宇宙】（N3）

授受三角形：我→别人＝あげる / 别人→我＝くれる / 我←别人＝もらう

①～てあげる我帮别人
（我→别人）
②～てもらう别人帮我
（我←别人）
③～てくれる别人主动帮我
（别人→我）

📣【传闻表达宇宙】（N3）

①～そうだ（传闻）听说……
雨が降るそうだ。
  • 🧠 听说：普通形 + そうだ
②～そうだ（样态）看起来……
おいしそう。
  • 🧠 看起来：去い形容词い + そう
③～という叫做……
富士山という山。

PART 1：N3 生活宇宙（下）

🚶【状态变化宇宙】（N3）

核心问题：开始变化？越来越……？保持状态？放着不管？

①～ようになる以前不会 → 现在会了
日本語が話せるようになった。
  • 🧠 能力变化 / 习惯形成 / 自然成长
②～ていく现在 → 未来（越来越……）
人口が減っていく。
  • 🧠 从现在走向未来
③～てくる过去 → 现在（逐渐……）
日本語が上手になってきた。
  • 🧠 变化走到眼前
④～たまま保持状态 / 不改变
ドアを開けたまま寝た。
  • 🧠 一直维持 / 不处理
⑤～っぱなし放着不管 / 懒得收拾（偏负面）
電気をつけっぱなしにした。
  • 🧠 负面版：たまま

💬【解释说明宇宙】（N3）

①～んです其实是……（解释原因）
頭が痛いんです。
  • 🧠 给理由 / 说明情况
②～わけだ原来如此！
10年住んでいる。上手なわけだ。
③～ということだ换句话说 / 转述总结
明日は休みだということだ。
  • 🧠 三兄弟：解释＝んです / 理解＝わけだ / 转述＝ということだ

😭【感情表达宇宙】（N3）

①～たい我想……
日本へ行きたい。
②～たがる别人想……
子どもが遊びたがっている。
③～そうだ（样态）看起来……
おいしそう。
④～てしまう完了！/糟了！（完成 or 后悔）
食べてしまった。
  • 🧠 完成 / 后悔

🚫【禁止义务宇宙】（N3）

四兄弟：必须＝なければならない / 不用＝なくてもいい / 禁止＝てはいけない / 允许＝てもいい

①～なければならない规则要求：必须
勉強しなければならない。
②～なくてもいい不用：没关系
行かなくてもいい。
③～てはいけない禁止：不许
入ってはいけない。
④～てもいい允许：可以
座ってもいいです。

🎓【敬语宇宙】（N3）

①お～になる尊敬别人
お帰りになります。
②～られる（尊敬）简易尊敬
先生が来られます。
③お～する我帮您（谦逊）
ご案内します。
④～させていただく得到允许（谦逊表达）
説明させていただきます。
  • 🧠 商务高频 / N2继续强化

PART N3+：剩余N3语法宇宙

动词变化（可能/受身/使役/使役受身）＋ 敬语完全体 ＋ 授受完全体——N3基础但贯穿N2、N1全程的地基语法。

⚙️【动词变化宇宙】（N3）

核心问题：这个动作是能做？被做？让做？还是被迫做？

①可能形能够……
日本語が話せる。
  • 🧠 能力 / 条件允许
②受身形被……
先生に褒められた。
③使役形让……
子どもに勉強させる。
④使役受身被迫……
母に野菜を食べさせられた。
  • 🧠 人生第一次崩溃文法（笑）
⚙️动词宇宙口诀一行记忆
能：可能
被：受身
让：使役
被迫：使役受身

🎩【敬语完全宇宙】（N3）

①尊敬语抬高别人
部長がお帰りになります。
  • 🧠 句型：お～になる
②谦让语降低自己
私がお持ちします。
  • 🧠 句型：お～する
③丁宁语普通礼貌
です・ます
④～させていただく恭敬地允许我……
発表させていただきます。
  • 🧠 日本职场最强文法
🎩敬语口诀一行记忆
别人高：尊敬
自己低：谦让
普通礼貌：丁宁
万能社畜：させていただく

🎁【授受完全宇宙】（N3）

①あげる我给别人
②くれる别人给我
③もらう我收到
④～てあげる帮别人做
⑤～てくれる别人帮我
⑥～てもらう请别人帮我
🎁授受口诀一行记忆
我给：あげる
别人给：くれる
我收：もらう
帮别人：てあげる
别人帮：てくれる
请帮忙：てもらう

PART 2：N2 Logic Universe（上）

情绪失控 / 被逼无奈 / 推理判断 / 时间瞬间 / 变化成长。

😭【情绪失控宇宙】（N2）

核心问题：控制不住？心里放不下？烦得要死？想得发疯？

①～ずにはいられない忍不住（身体先行动）
彼の話を聞いて、泣かずにはいられなかった。
  • 🧠 身体失控 / 行动失控
②～ないではいられない口语版：ずにはいられない
笑わないではいられない。
③～てならない一直挂念 / 放不下
将来が心配でならない。
  • 🧠 心理活动 / 持续状态
④～てしかたがない烦死了/热死了/累死了
暑くてしかたがない。
⑤～てたまらない欲望爆棚 / 强烈感情
会いたくてたまらない。
  • 🧠 强烈欲望 / 强烈感情
🔥情绪宇宙口诀一行记忆
身体忍不住：ずにはいられない
心里放不下：てならない
烦得受不了：てしかたがない
想得发疯：てたまらない

🚨【人生被逼宇宙】（N2）

N2超级高频家族：老板/责任/逻辑/现实 四兄弟

①～ざるを得ない老板逼你：没办法
残業せざるを得ない。
②～わけにはいかない责任逼你：不能不做
約束したから、断るわけにはいかない。
③～ないわけにはいかない逻辑逼你：必须承认
事実だから、認めないわけにはいかない。
④～よりほかない现实没路：只能……
待つよりほかない。
🚨人生四兄弟一行记忆
老板：ざるを得ない
责任：わけにはいかない
逻辑：ないわけにはいかない
现实：よりほかない

🔥【推理侦探宇宙】（N2）

①～わけだ原来如此！
10年日本に住んでいる。上手なわけだ。
②～はずだ逻辑推导：应该……
医者だから、知っているはずだ。
③～に違いない证据很多：肯定……
彼が犯人に違いない。
④～に相違ない新闻主播模式（更正式）
原因はこれに相違ない。
  • 🧠 书面版：に違いない
⑤～に決まっている100%
嘘に決まっている。
🔥侦探宇宙口诀一行记忆
突然懂：わけだ
逻辑：はずだ
基本确定：に違いない
正式确定：に相違ない
百分百：に決まっている

⏳【时间瞬间宇宙】（N2）

①～たとたん啪！刚一……
ドアを開けたとたん、猫が飛び出した。
②～かと思うと刚……马上又……
帰ったかと思うと、また出かけた。
③～て以来从那以后一直……
日本へ来て以来、日本語を勉強している。
④～に先立って正式开始前：先……
試合に先立って、挨拶があった。
⏳时间四兄弟一行记忆
瞬间：とたん
刚……又……：かと思うと
从那以后：て以来
正式开始前：に先立って

📈【变化成长宇宙】（N2）

①～つつある慢慢变化
景気は回復しつつある。
②～一方だ越来越……（停不下来）
人口は減る一方だ。
  • 🧠 通常：坏方向/持续变化
③～一方で同时发生
都市人口が増える一方で、地方は過疎化している。
④～ばかりになっている只差最后一步
出発するばかりになっている。
⑤～きる干到底！
走りきった。
⑥～かけ做到一半
食べかけのパン。
⑦～っぱなし放着不管
電気をつけっぱなしにした。
📈成长宇宙口诀一行记忆
慢慢变化：つつある
越来越：一方だ
同时变化：一方で
只差最后：ばかりになっている
干到底：きる
做到一半：かけ
放着不管：っぱなし

PART 3：N2 Logic Universe（下）

逆接对比 / 梦想与条件 / 后悔结果 / 限定强调 / という系列 / 顺序前提 / 易混Top20。

⚔️【虽然但是宇宙】（N2）

虽然……但是？即使……也没用？A成立不代表B？和预想相反？双面性？

①～ものの虽然……
日本語は話せるものの、漢字は苦手だ。
  • 🧠 正式版：けれども
②～ながら（も）虽然……（有缺点但还不错）
狭いながらも、住みやすい家だ。
  • 🧠 A有缺点，但还不错
③～とはいえ虽然说……（承认后补充）
春とはいえ、まだ寒い。
  • 🧠 承认事实，但要补充说明
④～にもかかわらず按理说……结果没有
雨にもかかわらず、多くの人が来た。
⑤～たところで即使做了也没意义
今さら謝ったところで、遅い。
  • 🧠 无意义假设
⑥～からといってA成立不代表B
高いからといって、おいしいとは限らない。
⑦～に反して预想相反
予想に反して、試験は簡単だった。
⑧～反面双面性
便利な反面、危険もある。
⚔️逆接宇宙口诀一行记忆
普通虽然：ものの
有缺点但：ながらも
虽说：とはいえ
尽管：にもかかわらず
即使也没用：たところで
A不代表B：からといって
和预想相反：に反して
双面性：反面

🎯【梦想实现宇宙】（N2）

①～べく为了目标（书面：ために）
合格すべく、毎日勉強している。
  • 🧠 书面版：ために
②～ものなら如果能……真想……（基本不可能）
戻れるものなら、戻りたい。
  • 🧠 基本不可能实现
③～さえ～ば只要……就……
お金さえあれば、幸せだ。
④～限り只要……就一直……
生きている限り、頑張る。
🎯梦想宇宙口诀一行记忆
奋斗目标：べく
不可能愿望：ものなら
唯一条件：さえ～ば
只要还……：限り

💥【后悔结果宇宙】（N2）

①～ばかりに偏偏因为……悲剧发生
嘘をついたばかりに、信頼を失った。
  • 🧠 负面因果
②～末に努力很久最后……
長い話し合いの末に、決定した。
③～ずじまい本来想做，结果没做成
日本へ行かずじまいだった。
  • 🧠 遗憾结局
④～あげく折腾半天坏结果
悩んだあげく、やめることにした。
💥后悔宇宙口诀一行记忆
因为……：ばかりに
长期努力：末に
没做成：ずじまい
折腾之后：あげく

🔒【限定强调宇宙】（N2）

①～こそ正是……
今こそ、頑張るべきだ。
②～しか～ない只有……
水しかない。
③～にすぎない不过是……
それは噂にすぎない。
④～にほかならない正是……
成功の理由は努力にほかならない。
  • 🧠 更正式的“正是”
🔒限定宇宙口诀一行记忆
强调：こそ
只有：しかない
不过：にすぎない
正是：にほかならない

📣【という宇宙】（N2）

①～ということだ听说 / 就是……
明日は休みだということだ。
②～というものだ这才叫……
努力するのが学生というものだ。
③～というわけだ原来如此
君は反対というわけだね。
④～というところだ大概……
合格率は50％というところだ。
📣という宇宙口诀一行记忆
传闻：ということだ
这才是：というものだ
原来：というわけだ
大概：というところだ

🌧️【不先A就不能B宇宙】（N2）

①～ないことには不做A无法判断B
見てみないことには、わからない。
②～うえで做完A决定B
調べたうえで、判断する。
③～てからでないと必须先A否则不行
確認してからでないと、答えられない。
🌧️顺序宇宙口诀一行记忆
不做不知道：ないことには
做完再决定：うえで
必须先做：てからでないと

PART N2+：剩余N2语法宇宙

自然变化 / 不愧宇宙 / 理由解释 / 让步补完 / 前提顺序——N2阅读里常被忽略但很实用的补完语法。

🌊【自然变化宇宙】（N2）

①～につれて自然变化，一起变化
年を取るにつれて、体力が落ちる。
  • 🧠 自然趋势
②～にしたがって规则变化，跟着变化
人口が増えるにしたがって、問題も増えた。
  • 🧠 书面版：につれて
🌊变化宇宙口诀一行记忆
自然：につれて
规律：にしたがって

👑【不愧宇宙】（N2）

①～だけあって不愧是……
プロだけあって、上手だ。
②～だけに正因为……
好きなだけに、残念だ。
③～だけのことはある果然名不虚传
高いだけのことはある。
👑不愧宇宙口诀一行记忆
真不愧：だけあって
正因为：だけに
果然值得：だけのことはある

🌧️【理由解释宇宙】（N2）

①～ものだから因为……（带感情解释）
子どもなものだから、許してください。
②～ことだから按那个人性格，一定……
彼のことだから、大丈夫だろう。
③～もの因为嘛……（撒娇解释）
行きたくないんだもの。
🌧️理由宇宙口诀一行记忆
带感情：ものだから
按性格：ことだから
撒娇：もの

⚔️【让步补完宇宙】（N2）

①～にしても即使……也……
高いにしても、高すぎる。
②～にしては对于……来说，出乎意料
初めてにしては上手だ。
③～とはいうものの虽说……但是……
春とはいうものの、寒い。
  • 🧠 书面版：とはいえ
⚔️让步宇宙口诀一行记忆
即使：にしても
对于……来说：にしては
虽说：とはいうものの

📈【前提顺序宇宙】（N2）

①～うえで做完A，再B
調査したうえで決める。
②～うえは既然……就……
引き受けたうえは、最後までやる。
③～うえに而且……，再加上……
安いうえに、おいしい。
📈うえ口诀一行记忆
之后：うえで
既然：うえは
而且：うえに

PART 4：N1 Advanced Universe（上）

作者评论 / 新闻报道 / 客观评价 / 因果分析 / 无奈被迫。

👑【作者评论宇宙】（N1）

作者想评价什么？值得/不值得？于心不忍？无法承受？

①～に値する值得……
この映画は見るに値する。
  • 🧠 有价值 / 值得推荐
②～に足る足以……
信頼に足る人物だ。
  • 🧠 正式版：に値する
③～に足りない不值得……
驚くに足りない。
  • 🧠 没什么大不了
④～に忍びない于心不忍
見るに忍びない光景だった。
⑤～にたえない无法承受
悲しみにたえない。
👑作者宇宙口诀一行记忆
值得：に値する
足够值得：に足る
不值得：に足りない
于心不忍：に忍びない
无法承受：にたえない

📰【新闻报道宇宙】（N1）

①～にほかならない原因只有一个：正是……
成功は努力の結果にほかならない。
②～にすぎない不过是……
それは噂にすぎない。
③～ならでは只有……才能……
京都ならではの景色。
  • 🧠 独一无二
④～まみれ全是……
泥まみれになった。
⑤～ずくめ全都是好事/清一色
黒ずくめの男。
良いことずくめ。
📰新闻宇宙口诀一行记忆
正是：にほかならない
不过：にすぎない
只有……才有：ならでは
满身都是：まみれ
清一色：ずくめ

⚖️【客观评价宇宙】（N1）

①～からすると从……来看
表情からすると、怒っているようだ。
②～からいえば按……来说
経験からいえば、難しい。
③～に即して依据……
現状に即して考える。
④～に沿って沿着……
計画に沿って進める。
⑤～を踏まえて基于……
結果を踏まえて判断する。
⚖️评价宇宙口诀一行记忆
从……看：からすると
按……说：からいえば
依据现实：に即して
按照计划：に沿って
基于前提：を踏まえて

🔍【因果分析宇宙】（N1）

①～ばかりに偏偏因为……（悲剧发生）
信じたばかりに、騙された。
  • 🧠 负面因果
②～ものだから因为……（解释理由）
子どもなものだから、わからなかった。
  • 🧠 带感情色彩
③～こととて因为特殊情况
初めてのこととて、失礼しました。
④～ゆえに因为……（文学味/书面味）
若さゆえに失敗した。
  • 🧠 文学味 / 书面味
🔍因果宇宙口诀一行记忆
导致悲剧：ばかりに
带情绪解释：ものだから
特殊原因：こととて
文学原因：ゆえに

🚧【无奈被迫宇宙】（N1）

①～ざるを得ない不得不……（N2复习）
残業せざるを得ない。
②～ないではすまない不做不行
謝らないではすまない。
  • 🧠 社会责任 / 后果严重
③～ずにはすまない文语版：ないではすまない
罰せずにはすまない。
④～羽目になる落得……（倒霉结果）
徹夜する羽目になった。
  • 🧠 倒霉结果
⑤～かねる难以……
賛成しかねる。
⑥～かねない很可能……
事故になりかねない。
🚧被迫宇宙口诀一行记忆
不得不：ざるを得ない
社会上过不去：ないではすまない
文语版：ずにはすまない
倒霉下场：羽目になる
难以接受：かねる
可能出事：かねない

PART 5：N1 Advanced Universe（下）

极端表达 / 文学书面 / 政治经济 / 限定强化 / N1易混Top20。

🌪️【极端表达宇宙】（N1）

岂止…… / 万万没想到…… / 别说……甚至……

①～どころかA？根本不是！而是B！
日本語どころか、英語も話せない。
  • 🧠 程度完全相反
②～はおろか连A都……更别说B
漢字はおろか、ひらがなも書けない。
  • 🧠 书面版：どころか
③～までもない不用……（理所当然）
言うまでもない。
④～に至っては尤其是……（更加……）
東京は暑いが、大阪に至っては40度近い。
⑤～と思いきや本以为……结果……
帰ったと思いきや、また出かけた。
  • 🧠 剧情反转神器
🌪️极端宇宙口诀一行记忆
根本不是：どころか
更别说：はおろか
不用说：までもない
尤其：に至っては
本以为：と思いきや

🎭【文学书面宇宙】（N1）

①～べくもない根本不可能……
理由は知るべくもない。
②～ずくめ全都是……
黒ずくめの男。
③～が早いか刚一……马上……
席に着くが早いか、寝てしまった。
  • 🧠 文学版：とたん
④～なり刚……立刻……
家に帰るなり、寝た。
⑤～そばから刚做完马上又……
覚えたそばから忘れる。
  • 🧠 白学了……
🎭文学宇宙口诀一行记忆
根本不知道：べくもない
刚一：が早いか
一……就：なり
刚学就忘：そばから

🏛️【政治经济宇宙】（N1）

新闻、论文、N1阅读高频

①～をめぐって围绕……争论
環境問題をめぐって議論する。
②～に基づいて根据……制定
法律に基づいて判断する。
③～に照らして按照……衡量
経験に照らして考える。
④～を皮切りに以……开始连续展开
東京を皮切りに全国公演を行う。
⑤～を契機に以……为契机发生变化
留学を契機に人生が変わった。
🏛️政治宇宙口诀一行记忆
围绕：をめぐって
依据：に基づいて
参照：に照らして
第一站：を皮切りに
转折点：を契機に

🔒【N1限定强化宇宙】

①～のみならず不仅……而且……
日本のみならず、中国でも人気だ。
  • 🧠 书面版：だけでなく
②～に限らず不限于……全部都……
学生に限らず、社会人も参加できる。
③～ならまだしも如果A还好，但B……
一万円ならまだしも、十万円は高い。
④～といえども即使……也……
子どもといえども、責任がある。
  • 🧠 文学版：でも
🔒限定宇宙口诀一行记忆
不仅：のみならず
不限于：に限らず
如果A还好：ならまだしも
即使：といえども

PART 5.5：N1 补完计划（低频N1宇宙）

古典书面 / 极限限定 / 极端结果 / 热血主角 / 特殊环境 / 文学夸张——阅读高分区，但出现频率不高，属于"锦上添花"型语法。

🏯【古典书面宇宙】（N1）

核心问题：这是古文味？法律味？武士味？公告牌味？

①～んがため（に）为了某个信念，拼上一切
家族を守らんがために戦った。
  • 🧠 古典版：ために
②～べからず绝对禁止
立入るべからず。
  • 🧠 神社石碑版：てはいけない
③～まじき不应该……
教師としてあるまじき行為。
  • 🧠 文学版：べきではない
④～たる作为……，理应……
社会人たるもの、責任を持つべきだ。
  • 🧠 古典版：として
🏯古典宇宙口诀一行记忆
武士为了：んがため
石碑禁止：べからず
不该如此：まじき
身为……：たる

🔒【极限限定宇宙】（N1）

①～たりとも连……都不允许
一円たりとも無駄にできない。
②～といえども即使……也……
子どもといえども、責任がある。
③～に限ったことではない不仅仅是……
日本に限ったことではない。
🔒极限宇宙口诀一行记忆
连……都：たりとも
即使……：といえども
不只是……：に限ったことではない

🌪️【极端结果宇宙】（N1）

①～が最後一旦……就完了
始めたが最後、途中でやめられない。
②～たが最後只要……，必然……
彼に見つかったが最後、逃げられない。
③～とあれば如果是为了……，什么都做
子どものためとあれば、頑張れる。
🌪️结果宇宙口诀一行记忆
开始就完：が最後
被发现就惨：たが最後
如果为了：とあれば

💪【热血主角宇宙】（N1）

①～をものともせず困难？无所谓！
困難をものともせず前進した。
②～をよそに别人担心，我不管
親の心配をよそに遊んでいる。
③～にもまして比以前更……
去年にもまして暑い。
💪热血宇宙口诀一行记忆
无视困难：ものともせず
无视别人：をよそに
更加：にもまして

🌍【特殊环境宇宙】（N1）

①～にあって特殊时代，特殊环境
戦争中にあって、希望を失わなかった。
②～にあっても即使身处……
困難にあっても諦めない。
③～にひきかえ和……形成鲜明对比
兄にひきかえ、弟は静かだ。
🌍环境宇宙口诀一行记忆
特殊环境：にあって
即使如此：にあっても
鲜明对比：にひきかえ

🎭【文学夸张宇宙】（N1）

①～んばかりだ简直像要……
泣き出さんばかりの表情。
  • 🧠 几乎要：そうなほど
②～にかたくない不难……
想像にかたくない。
③～べくもない根本不可能……
知るべくもない。
🎭文学宇宙口诀一行记忆
简直要：んばかり
不难：かたくない
根本不能：べくもない
