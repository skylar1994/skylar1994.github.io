▶ 1. 时间、顺序
〜が早いかN1
接续：动词辞书形 + が早いか
点击查看释义
刚一～就
例：彼は家に着くが早いかパソコンを開けた。
他刚一进家门就打开了电脑。
〜や／〜や否やN1
接续：动词辞书形 + や／や否や
点击查看释义
刚一～就（书面语）
例：空が暗くなるや否や大雨が降り出した。
天刚一暗下来就下起了大雨。
〜そばからN1
接续：动词辞书形/タ形 + そばから
点击查看释义
刚～马上就（又）（重复发生）
例：覚えるそばから忘れてしまう。
刚记住马上就忘了。
〜なりN1
接续：动词辞书形 + なり
点击查看释义
刚一～就（紧接着意外行为）
例：父は帰宅するなり酒を飲み始めた。
爸爸刚一回家就开始喝酒了。
〜てからというものN1
接续：动词テ形 + からというもの
点击查看释义
自从～之后（大变化）
例：彼女ができてからというもの、毎日が楽しい。
自从交了女朋友之后，每天都很快乐。
〜を限りにN1
接续：名词 + を限りに
点击查看释义
以～为最后 / 截止到
例：今月を限りに退職します。
到这个月底我就退休/离职了。
〜をもってN1
接续：名词 + をもって
点击查看释义
以～（时间点） / 凭借
例：12月31日をもって閉店いたします。
到12月31日闭店。
〜というところだN1
接续：数量/名词 + というところだ
点击查看释义
大概～左右
例：費用は100万円というところだ。
费用大概100万日元左右。

例：彼の実力をもってすれば不可能ではないだろう。

〜なりに／〜なりのN1

以～的方式 / 虽然～但相应地
例：子供なりにいろいろ考えているのだ。
孩子有孩子自己的考虑。

〜に即してN1

〜に則してN1

〜に鑑みてN1

点击查看释义

例：この深刻な状況に鑑みて、対策を急ぐ必要がある。

例：優勝候補だけに実力は確かだ。

〜だけあってN1
接续：连体形 + だけあって

不愧是 / 不枉
例：彼は長年稽古しただけあって、素晴らしい演奏だった。

〜だにN1
接续：动词辞书形 + だに
点击查看释义

例：想像するだに恐ろしい。

〜にしてN1
接续：名词 + にして
点击查看释义

例：この味はプロの料理人にして初めて出せる味だ。

他在50岁时才第一次做了父亲。
〜たりともN1
接续：数量词(1 + 助数词) + たりとも
点击查看释义
即便是～数值也（不）
例：一円たりとも無駄にできない。
即使是一日元也不能浪费。
〜からある／〜からするN1
接续：数量词 + からある/からする
点击查看释义
足有 / 多达（强调数量大）
例：10億円からするマンションを購入した。
买了价值10亿日元的公寓。
〜といったところだN1
接续：名词/数量 + といったところだ
点击查看释义
大概就是～（无更大不了）
例：結果はまあまあといったところだ。
结果也就是一般般吧。
