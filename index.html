🌱【习惯养成宇宙】（N3）

核心问题：这是自己努力？自然变化？个人决定？规则/环境决定？

①～ようにする努力培养习惯 / 努力让自己做到
毎日、日本語を勉強するようにしている。
  • 🧠 自己控制 / 自己坚持 / 自己训练
  • 关键词：努力让自己做到
②～ようになる练着练着自然会了 / 结果变化 / 能力变化
日本語が話せるようになった。
  • 🧠 能力变化 / 习惯形成 / 自然成长
③～ことにする我决定 / 自己拍板
来年、日本へ行くことにした。
  • 🧠 自己拍板 / 自己决定
④～ことになる公司/学校/规则决定 / 环境决定
転勤することになった。
  • 🧠 别人决定 / 环境决定 / 制度决定

🕒【时间顺序宇宙】（N3）

①～てから做完A → 做B
ご飯を食べてから勉強する。
②～たところだ刚刚完成
今、帰ったところです。
③～ところだ正准备
今から出かけるところだ。
④～ているところだ正在进行
今、食べているところです。
⑤～たばかりだ虽然过去一阵子，但感觉：刚刚！（主观）
日本へ来たばかりです。
  • 🧠 主观上的：才……

🤔【推测宇宙】（N3）

①～ようだ像……（自己观察/自己判断）
雨が降るようだ。
  • 🧠 自己观察 / 自己判断
②～らしい听说……（别人说/新闻说/网络说）
明日は雨らしい。
③～みたいだ口语版：～ようだ
おいしいみたいだ。
  • 注意：表达“看起来好吃”更常用 おいしそう（样态）。
④～はずだ逻辑推理：应该……
医者だから、知っているはずだ。
  • 🧠 根据已知条件 → 推导结果

🎯【目的愿望宇宙】（N3）

①～ために为了梦想
日本へ行くために勉強する。
②～ように为了能够……（能力变化）
合格できるように頑張る。
  • 区别：主动目的＝ために / 能力变化＝ように
③～ようと思う准备开始做
毎日運動しようと思う。
④～つもりだ已经决定
留学するつもりです。
⑤～ことのないよう（に）为了不要……/希望不会……
二度と同じ失敗をすることのないよう、注意してください。
  • 🧠 「ように」的否定目的用法，提醒对方避免重蹈覆辙

🔀【条件宇宙】（N3）

条件四兄弟：万能＝たら / 逻辑＝ば / 话题＝なら / 自然规律＝と

①～たら如果……（最万能）
②～ば只要……（逻辑条件）
③～なら既然说到……
日本へ行くなら、京都がおすすめ。
④～と自动发生（自然规律）
春になると暖かくなる。
⑤～でもしたら万一（做了）……的话（担心糟糕后果，N1级用法）
もし怪我でもしたら、大変なことになる。
  • 🧠 たら的加强版，举出一个最坏的可能性并表示担忧

❤️【授受请求宇宙】（N3）

授受三角形：我→别人＝あげる / 别人→我＝くれる / 我←别人＝もらう

①～てあげる我帮别人
（我→别人）
②～てもらう别人帮我
（我←别人）
③～てくれる别人主动帮我
（别人→我）

📣【传闻表达宇宙】（N3）

①～そうだ（传闻）听说……
雨が降るそうだ。
  • 🧠 听说：普通形 + そうだ
②～そうだ（样态）看起来……
おいしそう。
  • 🧠 看起来：去い形容词い + そう
③～という叫做……
富士山という山。

🚶【状态变化宇宙】（N3）

核心问题：开始变化？越来越……？保持状态？放着不管？

①～ようになる以前不会 → 现在会了
日本語が話せるようになった。
  • 🧠 能力变化 / 习惯形成 / 自然成长
②～ていく现在 → 未来（越来越……）
人口が減っていく。
  • 🧠 从现在走向未来
③～てくる过去 → 现在（逐渐……）
日本語が上手になってきた。
  • 🧠 变化走到眼前
④～たまま保持状态 / 不改变
ドアを開けたまま寝た。
  • 🧠 一直维持 / 不处理
⑤～っぱなし放着不管 / 懒得收拾（偏负面）
電気をつけっぱなしにした。
  • 🧠 负面版：たまま

💬【解释说明宇宙】（N3）

①～んです其实是……（解释原因）
頭が痛いんです。
  • 🧠 给理由 / 说明情况
②～わけだ原来如此！
10年住んでいる。上手なわけだ。
③～ということだ换句话说 / 转述总结
明日は休みだということだ。
  • 🧠 三兄弟：解释＝んです / 理解＝わけだ / 转述＝ということだ

😭【感情表达宇宙】（N3）

②～たがる别人想……

③～そうだ（样态）看起来……
おいしそう。
④～てしまう完了！/糟了！（完成 or 后悔）
食べてしまった。
  • 🧠 完成 / 后悔

🚫【禁止义务宇宙】（N3）

四兄弟：必须＝なければならない / 不用＝なくてもいい / 禁止＝てはいけない / 允许＝てもいい

①～なければならない规则要求：必须
勉強しなければならない。
②～なくてもいい不用：没关系
行かなくてもいい。
③～てはいけない禁止：不许
入ってはいけない。
④～てもいい允许：可以
座ってもいいです。
⑤～ても差し支えない即使……也没关系（更正式的允许，N1级用法）
この件は、担当者に直接連絡していただいても差し支えありません。
  • 🧠 「てもいい」的郑重书面版，常见于商务/正式场合的许可表达

PART N3+：剩余N3语法宇宙

动词变化（可能/受身/使役/使役受身）＋ 敬语完全体 ＋ 授受完全体——N3基础但贯穿N2、N1全程的地基语法。

⚙️【动词变化宇宙】（N3）

核心问题：这个动作是能做？被做？让做？还是被迫做？

①可能形能够……
日本語が話せる。
  • 🧠 能力 / 条件允许
②受身形被……
先生に褒められた。
③使役形让……
子どもに勉強させる。
④使役受身被迫……
母に野菜を食べさせられた。
  • 🧠 人生第一次崩溃文法（笑）
⚙️动词宇宙口诀一行记忆
能：可能
被：受身
让：使役
被迫：使役受身

🎩【敬语完全宇宙】（N3）

①尊敬语抬高别人
部長がお帰りになります。
  • 🧠 句型：お～になる
②谦让语降低自己
私がお持ちします。
  • 🧠 句型：お～する
③丁宁语普通礼貌
です・ます
④～させていただく恭敬地允许我……
発表させていただきます。
  • 🧠 日本职场最强文法
🎩敬语口诀一行记忆
别人高：尊敬
自己低：谦让
普通礼貌：丁宁
万能社畜：させていただく

②くれる别人给我
③もらう我收到

⑥～てもらう请别人帮我

③～一方で同时发生

④～ばかりになっている只差最后一步

⚔️【虽然但是宇宙】（N2）

虽然……但是？即使……也没用？A成立不代表B？和预想相反？双面性？

①～ものの虽然……
日本語は話せるものの、漢字は苦手だ。
  • 🧠 正式版：けれども
②～ながら（も）虽然……（有缺点但还不错）
狭いながらも、住みやすい家だ。
  • 🧠 A有缺点，但还不错
③～とはいえ虽然说……（承认后补充）
春とはいえ、まだ寒い。
  • 🧠 承认事实，但要补充说明
④～にもかかわらず按理说……结果没有
雨にもかかわらず、多くの人が来た。
⑤～たところで即使做了也没意义
今さら謝ったところで、遅い。
  • 🧠 无意义假设
⑥～からといってA成立不代表B
高いからといって、おいしいとは限らない。
⑦～に反して预想相反
予想に反して、試験は簡単だった。
⑧～反面双面性
便利な反面、危険もある。
⚔️逆接宇宙口诀一行记忆
普通虽然：ものの
有缺点但：ながらも
虽说：とはいえ
尽管：にもかかわらず

⏱️【契机节点宇宙】（N1）

①～を境に以……为界（前后发生变化）
結婚を境に、生活が大きく変わった。
②～を機に以……为契机
就職を機に、一人暮らしを始めた。
③～を振り出しに以……为起点（陆续展开）
東京を振り出しに、全国ツアーが始まった。
  • 🧠 常用于事件按顺序陆续展开的起点
④～を控え・～を控えて・～を控えた临近……，在……之前
試験を控えて、緊張している。
⑤～を経て经过……（阶段/过程）
長い交渉を経て、契約が成立した。
⏱️契机节点口诀一行记忆
以此为界：を境に
以此为契机：を機に
以此为起点：を振り出しに
临近：を控えて
经过：を経て

🙈【无视轻视宇宙】（N1）

不顾一切？置之不理？敷衍了事？

①～も顧みず・～を顧みず不顾……
危険も顧みず、救助に向かった。
②～をものともせずに不顾……，不畏……
批判をものともせずに、自分の信念を貫いた。
  • 🧠 带敬佩语气，强调克服困难、毫不在意外界阻力
③～はそっちのけで・～をそっちのけで丢开……不管，只顾……
宿題はそっちのけで、ゲームに夢中になっている。
  • 🧠 带批评语气，本该做的事被搁置一边
④～を蔑ろにする忽视……，轻视……
基本を蔑ろにしてはいけない。
⑤～をなおざりにして对……敷衍了事，草草应付
健康をなおざりにして働き続けた。
🙈无视轻视口诀一行记忆
不顾：も顧みず
不畏：をものともせずに
丢开不管：そっちのけで
轻视：を蔑ろにする
敷衍了事：をなおざりにして

💬【口语惯用宇宙】（N1/口语）

日常对话、抱怨吐槽、固定副词短语

①～んじゃなかった不应该……（后悔的口语说法）
あんな店に行くんじゃなかった。
  • 🧠 「するべきではなかった」的口语随意说法
②～んだって・～んですって据说……（口语传闻）
来月引っ越すんだって。
③～ってば说了……嘛（不耐烦地重申）
もう分かったってば。
  • 🧠 表示已经说过、对方还没理解或听从的不耐烦语气
④～でもって用……（口语版の手段）
この包丁でもって切ってください。
⑤～でも何でもない・～くも何ともない根本算不上……/根本没什么……
これは秘密でも何でもない。
  • 🧠 强烈否定前项的定性，语气随意直接
⑥いざ～となると・いざ～となれば・いざ～となったら一旦……的话（事到临头）
いざ本番となると、緊張してしまう。
  • 🧠 强调真到了那个关头，情况会与设想不同
⑦今ひとつ～还差一点……，不够……
この作品は今ひとつ面白くない。
⑧～もそこそこに……也顾不上，草草……
朝食もそこそこに、家を飛び出した。
  • 🧠 因为着急，本该做好的事情被匆匆带过
⑨たかが～（くらい）で只不过……而已（不至于）
たかが遅刻くらいで、そんなに怒らなくても。
⑩ただでさえ本来就……（更别说……）
ただでさえ忙しいのに、これ以上仕事を増やさないで。
⑪案の定果然（不出所料）
案の定、彼は遅刻した。
⑫一向に～ない一点也不……，丝毫不……
景気は一向に良くならない。
⑬今にも～そう眼看就要……
今にも雨が降りそうだ。
⑭お言葉に甘えて承蒙好意（那我就不客气了）
お言葉に甘えて、お先に失礼します。
  • 🧠 郑重接受对方好意时的寒暄套话

据说：んだって

根本不是：でも何でもない

📐【副词固定搭配宇宙】（N1）

书面固定搭配：数量超出、被认为、根据情况

①～ものと思われる被认为……（客观推测）
今後も需要は増加するものと思われる。
②～ようによっては根据……的方式/情况不同
考えようによっては、これはチャンスだ。
③～からある・～からする・～からの表数量、程度或范围超过，……以上
100人からある大所帯だ。
  • 🧠 前接数量词，强调"多达……以上"的惊人程度
④～（で）すら甚至连……（也）
専門家ですら分からない問題だ。
⑤ただ～のみだ仅仅……而已（别无他求）
あとはただ結果を待つのみだ。
📐副词固定搭配口诀一行记忆
被认为：ものと思われる
看情况：ようによっては
数量超出：からある
甚至连：ですら
仅仅而已：ただ～のみだ

⚔️【让步逆接补完宇宙】（N1）

让步逆接 / 出乎意料 / 既然如此 / 选择疑问，一次性补完易混用法

①～をもってしても即使凭借……也（不能/无法）
彼の実力をもってしても、この試合に勝つのは難しかった。
  • 🧠 后接消极结果，强调即便具备很强的条件也无法达成，语气郑重书面
②～であろうと无论是……都（让步）
どんな理由であろうと、暴力は許されない。
  • 🧠「であっても」的书面郑重说法，强调无论前提如何结论都不变
③いくら～たところで无论怎么……（也不会有结果）
いくら後悔したところで、もう取り返しがつかない。
  • 🧠 后项多接消极、否定的结果，强调徒劳无功
④～にかかわらず不管……都/与……无关
天候にかかわらず、試合は予定通り行われる。
⑤～はずなのに明明应该……可是（结果与预期相反）
今日は休みのはずなのに、会社から電話がかかってきた。
  • 🧠 前项是本该成立的预期，后项接与预期相反的意外结果
⑥それでも即便如此，尽管这样
何度失敗しても、それでも彼はあきらめなかった。
⑦～ようと（～ようが）无论……都（不管怎样也……）
周りに何と言われようと、自分の信念を貫くつもりだ。
  • 🧠 常与「だれが」「なんと」「どんなに」等疑问词呼应，表示无论怎样结论都不变
⑧～ものではない不应该……（社会常理、道德上不该做）
人の悪口を言うものではない。
  • 🧠 表达一般性的社会常识或道德劝诫，语气委婉但带有告诫意味
⑨～からには既然……就（必然结果、决心）
やると言ったからには、最後までやり遂げるつもりだ。
⑩～わけなので正因为……所以（承接前文得出结论）
明日は試験があるわけなので、今日は早く寝ます。
  • 🧠 承接前面说明的情况，得出理所当然的结论，语气偏口语
⑪～べきなので因为应该……所以
健康は大切にするべきなので、無理なダイエットはやめた方がいい。
⑫それとも或者，还是（二选一，多用于疑问句）
コーヒーにしますか、それとも紅茶にしますか。
